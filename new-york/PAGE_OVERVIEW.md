# New York Software Development Page - Comprehensive Overview

## Page Structure & Layout

This is a premium landing page for Sigma Soft AI's New York software development services, designed with a phone-first approach and optimized for local NYC businesses. The page follows a modern, professional design that matches the main website's aesthetic while being specifically tailored for the New York market.

## Design Elements & Styling

### **Color Scheme**
- **Primary**: Teal (#3AA6A4) - used for buttons, highlights, and accents
- **Secondary**: Darker teal (#297474) - used for hover states
- **Dark**: Navy blue (#091E3E) - used for backgrounds and text
- **White/Light**: Used for backgrounds and contrast

### **Typography**
- **Primary Font**: MuseoModerno for headings and branding
- **Secondary Fonts**: Nunito and Rubik for body text
- **Font Weights**: Various weights for hierarchy and emphasis

### **Animations & Interactions**
- **WOW.js**: Scroll-triggered animations throughout the page
- **Hover Effects**: Buttons, cards, and interactive elements
- **Smooth Transitions**: All interactive elements have smooth transitions
- **Counter Animations**: Statistics count up when scrolled into view

### **Responsive Design**
- **Mobile-First**: Optimized for mobile devices
- **Breakpoints**: Responsive grid system for different screen sizes
- **Mobile-Specific**: Bottom CTA bar and hidden elements for mobile
- **Desktop Enhancements**: Floating CTA and additional features
