Instructions
  1. Fill out the form on the left with the testimonial details
  2. Review the preview and JSON output on the right
  3. Copy the JSON and add it to your assets/data/testimonials.json file
  4. Make sure to add a comma after the previous testimonial and before the new one
  5. For images, upload them to assets/images/ and reference them in the avatar field
JSON Structure:
{
  "id": 9,
  "name": "Client Name",
  "title": "Company Name",
  "quote": "Testimonial quote...",
  "avatar": "assets/images/client-image.jpg",
  "rating": 5,
  "statNumber": "300%",
  "statLabel": "Growth",
  "statType": "success",
  "services": ["Service 1", "Service 2"],
  "location": "Manhattan"
}
